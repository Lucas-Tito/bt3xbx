## 2. Rodada única do WSL

`port/x360/tools/f6_final.sh COMMIT BASE DESTINO_NOVO [--plano]`, da raiz limpa. Base de comparação
`4c85c039` (main do ensaio); código ensaiado inclui a 7b conforme a tarefa. O script cria worktrees destacados
`base`/`final`, copia só os gerados data/gs, usa dados somente leitura, dispara serviço de usuário limitado
a 5 GiB e espera `flock ~/wsl.lock` uma única vez em primeiro plano. Todos os passos dependentes ficam dentro
da mesma trava. O script não usa o CLUT16, que tem trava própria; a rede adicional de listas da F5 permanece
no `f5_final.sh`. Aqui estão completas as redes 1 a 5 da F6 e as redes de roteiros herdadas da F4/F5.

```sh
port/x360/tools/f6_final.sh HEAD 4c85c039 "$HOME/f6-final-$(git rev-parse --short HEAD)" --plano
port/x360/tools/f6_final.sh HEAD 4c85c039 "$HOME/f6-final-$(git rev-parse --short HEAD)"
# Espera única, não olhar logs durante a execução. O shell só imprime o final ao terminar.
XDG_RUNTIME_DIR=/run/user/$(id -u) bash -c '
  while systemctl --user is-active --quiet bt3-f6-final-REPOR_SHA8; do sleep 300; done
  tail -5 "$HOME/f6-final-REPOR_SHA/julgamento.md"
  tail -1 "$HOME/f6-final-REPOR_SHA/provas.resumo"'
```

`XDG_RUNTIME_DIR` é definido pelo lançador se ausente. Não alterar HEAD/fontes das árvores isoladas durante a
rodada. Manter sessão WSL aberta. O comando de espera deve usar o SHA real impresso pelo lançador.
`FIM rc=0` mais `tudo certo no WSL` é aprovação; `FIM` sozinho não é. O script continua os casos independentes
após falha, conserva rc/duração/SHA256 do log de cada um em `casos.json` e termina com 1 se faltar ou falhar
qualquer caso. Uma ferramenta indisponível também é falha, nunca dispensa silenciosa.
